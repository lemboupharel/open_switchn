Why am I not getting a phone approval prompt?

This client uses the live backend only. Opening this page does not sign you in to Switchn or send a message.

Use Sign in below: an identity token is obtained from Firebase, you verify your phone through Switchn, and the server exchanges it for a bearer session. A successful challenge request does not by itself prove SMS/WhatsApp delivery. Never share a token, code or PIN in chat.

Phone sign-in requires the authorized Switchn Firebase project's client API key in SWITCHN_FIREBASE_API_KEY on the Node server. Android-only restrictions or a Google SMS fallback require the official app; this client never bypasses them.

If you already have an authorized API token, you can import it privately in your terminal:

npm run cli -- auth import

The server loads the private project .env automatically. Start with payments disabled:

npm run web

Enable SWITCHN_ALLOW_PAYMENTS=true only when you intend to submit a reviewed payment yourself, then restart the server.

These settings do not guarantee that the backend accepts the session or sends an operator prompt. No live payment has been verified with this client. Use the official app for a reliable real transfer.
